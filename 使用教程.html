二、快速上手（6 步）

1
导入素材点左上「📂 导入素材」或直接把一堆 PNG 拖进左侧虚线框（支持多选、支持整个文件夹）。
2
自动裁切完成素材会自动裁掉四周透明像素、并把最大边压到 1024 以内。卡片上标「已裁切」的就是处理过的。
3
拖到画布按住素材拖到中间画布，或双击素材直接放到画布中央。
4
摆位置、旋转、拉缩放选中后拖动移动；八个方块控制点自由拉伸（默认非等比，按住 Shift 等比）；顶部圆点旋转，按住 Shift 吸附 15°。
5
擦除多余部分按 E 切换橡皮擦，在图层上涂抹即可擦掉（笔刷大小用 [ ] 调）。擦错了 Ctrl+Z 撤销。
6
调色 + 导出右侧调不透明度 / 饱和度 / 对比度 / 亮度 / 色相偏移；最后点右上角「⬇ 导出 PNG」。

三、视频抠像（🎬 页签）

先回答一个高频问题：带透明度的动图到底存成什么？
GIF 只有 1 位 alpha——要么全透要么不透，边缘必然是锯齿，做特效素材不能用。 mp4 / mov 要带 alpha 必须上 ProRes 4444 或 HEVC with alpha，浏览器里根本编不出来。 所以这个工具给你三条真正能用的路，都在下方「输出格式」里。
1
切到 🎬 视频抠像 页签顶部两个页签，点一下就切。左边参数、中间原片 / 结果双画面、右边输出设置。
2
选视频点「📂 选择视频」，或直接把 mp4 / mov / webm / mkv 拖进来。
3
自动取背景色载入时会自动沿画面四边取样、识别出背景色并填进「取色」。识别不准就点「🎯 自动取背景色」重取，或用「💧 吸管」在左边原片上点一下。
4
调参数，看结果中间左边是原片、右边是抠完的结果（背景是棋盘格 = 透明）。拖时间轴或按 空格 播放 / ← → 逐帧检查。
5
选格式导出右边选输出格式 → 填名字 → 点「⬇ 开始导出」。

四个参数怎么调

参数作用什么时候动它

输出格式怎么选

格式产物用在哪
Sprite Sheet一张横向 / 网格排好的 PNG游戏引擎特效、粒子序列帧——UE / Unity / Cocos 直接切格子用
序列帧 zip一包带编号的 PNGAE / PR / 剪映 后期合成，或者要逐帧再加工
APNG单个 .png 文件，会动网页 / PPT / 文档里直接放的动图，浏览器和 Safari 都能播

四种都是完整 8 位 alpha 通道（256 级半透明），不是 GIF 的那种 1 位锯齿边。 勾选「统一裁剪到内容范围」后，所有帧会按统一的包围盒裁掉四周空白，雪碧图不浪费格子。

Sprite Sheet 坐标表（引擎靠它切帧）

选了 Sprite Sheet 后，右边会多出「坐标表」下拉。图集只是一张长图，引擎靠这张表才知道第几帧在哪个位置——导出时勾上就不用手数格子了。

选项产物什么时候选

等分网格格式长这样

{
  "image":   "fountain_sheet_5x5.png",
  "frameW": 533, "frameH": 243,
  "pad": 0, "stepX": 533, "stepY": 243,
  "cols": 5, "rows": 5, "count": 24,
  "fps": 12, "loop": true,
  "origin": "top-left"
}

frameW/H 是单帧尺寸，stepX/Y 是格子的步长（帧尺寸 + 间距）。切第 i 帧：

const col = i % m.cols, row = (i / m.cols) | 0;
ctx.drawImage(img,
  col * m.stepX, row * m.stepY, m.frameW, m.frameH,     // 源：第 i 帧在图集哪
  Math.round(x), Math.round(y), m.frameW, m.frameH);    // 目标：贴到屏幕哪
自己写播放器时记住三条：
  • 坐标要取整（Math.round）：非整数坐标会触发重采样，又慢又糊。像素风再配 ctx.imageSmoothingEnabled = false。
  • 别拿 requestAnimationFrame 的频率当帧率：144 Hz 屏上动画会快 12 倍。用时间累加器推进帧号。
  • 图集最长边别超 2048：部分移动端 GPU 贴图上限就是它，超了可能整张白图。导入时降帧率或降尺寸上限即可。
几个要提醒的：
  • 帧数 = 帧率 × 时长 ÷ 抽帧，48 帧 / 640×360 大约 600 KB。帧数太多时先调大「抽帧」或压低「尺寸上限」。
  • 「帧率」下面有一排 30 / 24 / 15 / 12 / 8 fps 快捷按钮，点一下就设好。页游和网页逐帧动效常用 8–12 fps，用 24 fps 导 48 帧纯属浪费——同一个素材 12 fps 只要 24 帧，图集还能小一半。
  • Sprite Sheet 单张最长边超过 8192 px 会被拒，减帧数或降尺寸即可。
  • 浏览器只能解它自己支持的编码。mp4 最好是 H.264；碰到解不了的，先用格式工厂 / ffmpeg 转成 H.264 mp4 再丢进来。
  • 视频同样全程本地处理，不会上传。

六、导出说明

exe 版

可指定任意目录；文件名留空则自动生成 atlas_日期_序号.png；同名文件自动加序号，不会覆盖旧图；可勾选导出后自动打开文件夹。

单文件 HTML / 网页版

受浏览器限制，图片保存到浏览器默认下载目录（Chrome/Edge 可改为「每次询问保存位置」）。如需指定目录，请用 Windows exe 版。

导出格式固定为 PNG（透明底）。可勾选「裁切到内容范围」自动去掉画布四周空白，只导出有像素的区域。

七、常见问题

为什么 exe 首次启动要等几秒？

单文件 exe 运行时会先把内置资源解压到临时目录，一般 2~4 秒，之后就正常了。需要系统已安装 Edge 或 WebView2 运行时（Windows 10/11 基本都自带）。

透明边没裁干净 / 裁多了？

左下角「导入设置」里调「透明阈值」：数值越大，越多的半透明像素被当作透明裁掉。默认是 6，边缘有半透明羽化的素材建议调到 20~40，纯色不透明的底图可更高。

素材被缩小了？

「尺寸上限」默认 1024，超过的会等比压缩到 1024。需要更高精度就把它改成 2048 / 4096 / 不限（改完对已导入的素材无效，需重新导入）。

擦除擦错了怎么办？

Ctrl+Z 逐步撤销；也可以点属性面板里的「↺ 还原擦除」一次性恢复整个图层。

iPhone 上怎么用？

用 Safari 打开网页版链接，点分享 → 「添加到主屏幕」，之后就能像 App 一样全屏打开。导入素材时会调用系统照片图库，导出会存到「下载」文件夹。

画布上东西多了会卡吗？

几十个图层基本流畅。如果卡，可以先把暂时不用的图层隐藏（👁），或把尺寸上限调低一些。

图片会被上传到网上吗？

不会。所有裁切、拼合、调色、抠像都在本地浏览器 / 本地窗口里完成，工具本身不发任何网络请求。

视频导进来没反应 / 预览是黑的？

多半是浏览器解不了这个编码。先确认是 H.264 的 mp4 或 webm；如果不是，用格式工厂 / ffmpeg 转一次再导入。另外视频必须是从本地选的，不能直接拖网址。

绿幕没抠干净，还剩一层绿边？

三步走：① 点「🎯 自动取背景色」重新取一次（实拍绿幕往往不是纯 #00ff00）；② 把「容差」调大一点；③ 边缘还有绿边就把「去溢色」调大、「边缘收缩」给一点正值。

抠完主体也被吃掉一块？

说明容差太大，或者主体里有跟背景接近的颜色。把「容差」调小，或者用「💧 吸管」在背景上多点几个位置取个中间值。主体本身就是绿色系的话，建议换成蓝幕拍。

APNG 在某某软件里不动 / 只显示第一帧？

APNG 是标准 PNG 的扩展，浏览器、Safari、Keynote 都支持；部分老软件只认静态首帧。遇到这种情况改用「序列帧 zip」或「Sprite Sheet」即可。
