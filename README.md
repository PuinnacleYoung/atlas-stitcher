# 素材拼接器 · Atlas Stitcher

离线单页工具，两个页签：

- **🧩 素材拼接**：导入 PNG → 自动裁掉透明边 → 拖到画布拼合 → 旋转缩放 / 擦除 / 调色 → 导出 PNG
- **🎬 视频抠像**：导入 mp4 / mov / webm → 色度抠像（绿幕 / 蓝幕）→ 输出带完整 alpha 的雪碧图 / 序列帧 / APNG

## 在线使用

**https://puinnacleyoung.github.io/atlas-stitcher/**

iPhone / iPad 用 Safari 打开后「分享 → 添加到主屏幕」，可当独立 App 用。

## 能做什么

### 素材拼接

- **自动裁切**：按 Alpha 裁掉四周透明区，最大边压到 1024（可调），不浪费像素
- **画布多图层**：拖动摆放、非等比缩放（按住 Shift 转等比）、旋转、显示/隐藏、拖拽排序
- **橡皮擦**：像素级擦除任意图层，支持 Ctrl+Z 撤销
- **逐图层调色**：不透明度 / 饱和度 / 对比度 / 亮度 / 色相偏移 / 模糊
- **导出**：透明底 PNG，可只导出内容范围；自定义命名或自动命名

### 视频抠像

- **自动识别背景色**：载入时沿画面四边取样，实拍绿幕（往往不是纯 `#00ff00`）也能一次抠干净
- **YCbCr 色度键控**：容差 / 羽化 / 去溢色 / 边缘收缩四个参数，边缘过渡平滑不发绿
- **四种输出**，全部是完整 8 位 alpha（不是 GIF 的 1 位锯齿边）：
  - Sprite Sheet PNG — 游戏引擎特效、粒子序列帧
  - 序列帧 zip — AE / PR 后期合成
  - APNG — 网页 / PPT 里直接放的动图
  - 当前帧 PNG — 单张取帧

> 浏览器里编不出带 alpha 的 mp4（需要 ProRes 4444 / HEVC with alpha 编码器），
> GIF 又只有 1 位 alpha，所以工具走的是上面这三条真能用的路。

## 本地离线用

仓库里的 `素材拼接器_离线网页版.zip` 下载解压后双击 HTML 即用，**不联网、不安装**。

需要「导出到指定目录」时用 Windows 版 exe（14 MB，见本地分发包）。

## 隐私

纯前端运行，图片 / 视频不会上传到任何服务器，页面加载后断网照样能用。

## 技术

单个 HTML 文件，零依赖，Canvas 2D 实现；APNG / ZIP 编码器为手写实现（无第三方库）；
Windows exe 由 pywebview + PyInstaller 打包。
